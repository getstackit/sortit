# Sortit Tags

Use `command sortit tags list` to fetch the tag catalog.

## Command

```bash
command sortit tags list
```

Use this before issue search or creation when tag selection matters. Pair it with `$sortit-search` to find existing issues, or `$sortit-create` when recording new tagged work.
