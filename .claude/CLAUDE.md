## Sortit Agent Workflow

Use Sortit as the durable work loop during coding, review, planning, and debugging.

- Claude Code should use the installed Sortit skills and prefer MCP tools when they are available.
- Search Sortit before creating follow-on work.
- Recall relevant memories before deciding — prior decisions, constraints, and patterns should guide the work, not be rediscovered or contradicted.
- Drive the issues you worked on to their right state — record progress, refine when understanding changed, close when finished, iterate when work remains.
- Create or refine follow-on issues instead of leaving deferred work only in chat.
- Create a memory for durable decisions, lessons, constraints, patterns, references, or concepts (the canonical profile of a noun).
- Use the Sortit wrap-up checklist before final responses for non-trivial work.
- Leave uncertain corpus-wide cleanup as proposals for human review.

Installed by `sortit agent install --instructions` (dev).
